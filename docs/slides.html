01 · Project objectives

Why a barber shop needs a database

Walk-in queues, paper appointment books and cash-only records make a busy shop lose customers, double-book barbers and guess at its numbers. barberOS puts the whole shop on one relational database.

01

Online booking

Customers book a service, barber and time slot themselves — 24/7, with real-time availability.

02

Zero double-booking

Business rules (overlaps, working hours, time off, cancellation window) are enforced inside the database.

03

Run the chair

Barbers manage their day: start visits, check out payments & tips, set hours, see earnings.

04

Know the business

The owner manages staff, services and prices, and sees revenue, ratings and top services.

Course alignment: E-R design → relational schema with constraints → implementation in PostgreSQL using SQL DML and procedural programming (PL/pgSQL stored functions + triggers) → working web application interface.

03 · Scope of work

What we will build — and what we won’t

In scope

  • Account registration, login, role-based access (3 roles)
  • Service catalogue & barber profiles with ratings
  • 4-step booking with live availability; reschedule & cancel
  • Barber day view: start, no-show, checkout (payment + tip)
  • Working hours & time-off management
  • Reviews & ratings; loyalty points
  • Owner CRUD for barbers, services, customers, appointments
  • Dashboard: revenue, bookings, cancellations, top barbers/services
  • E-R model, relational schema, SQL script with comments

Out of scope

  • Online card payment gateway (payment is recorded, not charged)
  • SMS / e-mail reminders
  • Multiple shop branches
  • Retail product inventory
  • Native mobile apps (web app is responsive instead)

Assumptions

  • One shop, 30-minute booking grid, prices in THB
  • One service per appointment; price is fixed at booking time
  • Cancellation allowed until 2 hours before start

04 · Roles of database users

Three stakeholders, three portals

👤 Customer

Books and manages their own visits.

  • Register / log in
  • Browse services & barbers
  • Book appointment (service → barber → slot)
  • View, reschedule, cancel bookings
  • Write / edit / delete reviews
  • Loyalty points & visit history
  • Manage profile, password, delete account
✂️ Barber

Runs their chair day-to-day.

  • Today’s appointments
  • Start visit / mark no-show
  • Checkout: record payment, tip, method
  • 14-day schedule & history
  • Set weekly working hours
  • Add / remove time off
  • Earnings (commission + tips) & reviews
  • Edit own profile
🏪 Owner

Manages the business.

  • Dashboard & reports
  • Hire / edit / deactivate barbers, commission, skills
  • Add / edit / hide / delete services & prices
  • Search all appointments, cancel / no-show
  • Customer list, spend, loyalty adjustment
  • Suspend / delete customers
  • Edit shop info, cancel window, loyalty rate
